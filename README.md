# 🎸 Band Crashers

**A pitch detection voice mobile game**

## 🎮 Overview

**Band Crashers** is an engaging mobile game that utilizes pitch detection to offer an interactive musical experience. Players use their voice to match pitches to score over the opponent. The game is developed using Unity and is designed to be both fun and educational, helping users improve their musical ear and pitch accuracy.

## 🛠️ Features

- **Voice-Controlled Gameplay**: Use your voice to control game mechanics by matching musical pitches.
- **Pitch Detection Algorithm**: Real-time analysis of vocal input to determine pitch accuracy.
- **Interactive Levels**: Progress through levels that increase in difficulty, introducing new musical challenges.
- **Visual Feedback**: Immediate visual indicators to show pitch accuracy and help players improve.
- **Cross-Platform Support**: Built with Unity, allowing deployment on both Android and iOS devices.

## 📦 Tech Stack

- **Game Engine**: Unity
- **Programming Language**: C#
- **Pitch Detection**: SRH (Summation of Residual Harmonics) by T. Drugman and A. Alwan
- **Version Control**: Unity version control

## 🚀 Getting Started

### Prerequisites

- [Unity](https://unity.com/) installed (version compatible with the project)
- [Git](https://git-scm.com/) installed

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/meowyboii/band-crashers-repo.git
   ```

2. **Open the project**:

   - Launch Unity Hub.
   - Click on "Add" and select the cloned `band-crashers-repo` directory.
   - Open the project in Unity.

3. **Run the game**:

   - Press the Play button in Unity to start the game in the editor.
   - For mobile deployment, configure the build settings for Android or iOS.

## ✅ Usage

1. **Start the game**: Launch the game on your device.
2. **Follow prompts**: The game will prompt you to produce specific musical pitches.
3. **Match pitches**: Use your voice to match the target pitches as accurately as possible.
4. **Progress through levels**: Successfully matching pitches will allow you to advance to more challenging levels.
